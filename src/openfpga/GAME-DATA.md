# Add your own game files

The Go preparation tools and Pocket Sync plugin now live in
[zenibako/butterscotch-pocket](https://github.com/zenibako/butterscotch-pocket),
the installation and release home for Butterscotch Pocket.

Follow [Add your own game files](https://github.com/zenibako/butterscotch-pocket/blob/main/GAME-DATA.md)
for supported game versions, preparing your own installation, Pocket Sync and
manual SD-card installation. No commercial game data is included in releases.

The runner and Pocket platform source remain in this fork. Historical Python/C
conversion tools remain under `tools/` as developer references; the current
standalone Go CLI and WASM plugin are maintained in the installation repository.
